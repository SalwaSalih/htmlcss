        1. Three ways to add CSS to HTML
        
        
        You can write CSS in three places. All three work, but an external stylesheet
            is the best choice for real websites: one file styles every page, and HTML and CSS stay separate.
        

        
        
            
        
                Recommended
                
        External stylesheet
        
                
        Put CSS in its own .css file and link it in <head>.
        
                
        index.html
        
                
        <head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 class="title">Hello</h1>
</body>
        
                
        style.css
        
                
        .title {
  color: royalblue;
  font-size: 40px;
}
        
            
        

            
        
                One page only
                
        Internal <style>
        
                
        Write CSS inside a <style> tag. It only affects that one page.
        
                
        index.html
        
                
        <head>
  <style>
    .title {
      color: royalblue;
    }
  </style>
</head>
<body>
  <h1 class="title">Hello</h1>
</body>
        
            
        

            
        
                Avoid
                
        Inline style=""
        
                
        Put CSS directly on one element with the style attribute. Hard to reuse and maintain.
        
                
        index.html
        
                
        <h1 style="color: royalblue;">
  Hello
</h1>
        
            
        
        
        
    
        

    
    
        
        
        2. CSS syntax
        
        
        A CSS rule picks some HTML elements (the selector) and gives them
            property: value pairs.
        
        
        
            
        h1 {
  color: red;
  font-size: 32px;
}
        
            
          
                
        • Selector which elements to style
          • 
                
        • Property what to change
          • 
                
        • Value how to change it
          • 
                
        • Each declaration ends with ; and the block is wrapped in { }
          • 
            
        
        
        
    
        

    
    
        
        
        3. Selectors: connecting CSS to HTML
        
        
        The selector is the bridge between your CSS file and your HTML.
        
        
        
        
            
                
                Selector table 11 common selectors – click to open
                
            
            
        
                
        
                    
        
                        
                            
        SelectorMatchesHTML
        
                                
                        
                            
        pEvery <p> element<p>Text</p>
        
                            
        .cardElements with class="card"<div class="card">
        
                            
        #logoThe one element with id="logo"<img id="logo">
        
                            
        nav a<a> anywhere inside <nav><nav><a>…</a></nav>
        
                            
        ul > li<li> that are direct children of <ul><ul><li>…</li></ul>
        
                            
        h1, h2Both <h1> and <h2><h1>…</h1><h2>…</h2>
        
                            
        a:hoverA link while the mouse is over it<a href="#">
        
                            
        li:first-childThe first <li> in its list<li>First</li>
        
                            
        input[type="email"]Inputs with that attribute value<input type="email">
        
                            
        p::first-lineThe first line of every paragraph<p>Long text…</p>
        
                            
        *Every elementAll elements
        
                                
                    
        
                
        
            
        
        
        
        
         If two rules set the same property, the more specific
            selector wins: #id beats .class, which beats p. If they are equally
            specific, the rule written last wins.
