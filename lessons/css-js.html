CSS Basics

HTML builds the page. CSS makes it look good: colors, sizes and spacing.

What is CSS?

CSS (Cascading Style Sheets) decides how HTML elements look. HTML says "this is a heading". CSS says "make the heading blue and big".

Try it: press the buttons to change the box with CSS

Hello!

A CSS rule has three parts:

h1 {
    color: blue;
}

/* h1     = selector  (which elements?)  */
/* color  = property  (what to change?)  */
/* blue   = value     (how?)             */
Every line ends with a semicolon ; and the rules go inside curly brackets { }.

Adding CSS to HTML

There are three places you can write CSS:

  1. In a <style> tag inside <head> – good for one page. We use this in this lesson.
  2. In a separate file linked with <link rel="stylesheet" href="style.css"> – best for real websites with many pages.
  3. In a style attribute on one element – quick, but hard to keep tidy.
<head>
  <style>
    p {
      color: green;
    }
  </style>
</head>
<body>
  <p>This text is green.</p>
</body>

Classes

A class lets you style only some elements. Give the element class="name" in HTML, and write .name in CSS (with a dot).
